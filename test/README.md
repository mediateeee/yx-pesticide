# 测试文件夹

## 对于 test.zip
这个文件夹用于存放用于测试应用程序的“被感染文件”。“被感染文件”由我自行新建，不会危害计算机及其操作系统，如果你对此持疑，请不要下载它。

注意：在26.2.19.0版本后，杀虫软件加入了特征匹配的功能，因此这个“被感染文件”失去了它原来的作用，只能用来测试杀虫软件的特征匹配功能是否有效。

### 使用方法
下载文件夹中的“test.zip”文件，解压后即可使用。注意检查你的文件夹是否是隐藏状态。

## 对于 测试文件生成器.py 以及 程序目录生成器.py
纯使用豆包进行生成。很便捷的生成我们需要的测试文件，完全随机。

### 使用方法
使用Python版本大于3.7.0的Python运行即可，然后用样本进行一次感染就可以使用了。
