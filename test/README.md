# 测试文件夹

### 使用方法
下载文件夹中的“test.zip”文件，解压后即可使用。注意检查你的文件夹是否是隐藏状态。

## 对于 test_detection.py
不需要真实病毒样本，无论是病毒本身还是病毒所感染的文件就可以测试杀虫软件。在项目根目录运行：

```text
python test/test_detection.py
```

用于验证判定规则：0 字节残留、无同名文件夹的普通 exe、仅文件名像样本但特征不符、版本号比较。

## 对于 测试文件生成器.py 以及 程序目录生成器.py
完全使用豆包进行生成。很便捷的生成我们需要的测试文件，完全随机。

### 使用方法
使用Python版本大于3.7.0的Python运行即可，然后用样本进行一次感染就可以使用了。
从26.8.22.0版本开始有了脚本进行判断，因此不需要进行一次真实感染就可以测试杀虫软件的功能。
但是这个脚本有一个小弊端，就是没有真正验证「头 64KB MD5 是否与 `VIRUS_HEAD_HASH` 匹配」这个计算环节本身，脚本默认已经验证且匹配。
